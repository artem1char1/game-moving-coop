# game-moving-coop

Проект кооперативной игры для Steam: изометрия, простая мультяшная графика, переноска мебели и денежная квота.

Unity 6000.6.7f1 (URP, C#), NGO 2.13.3 и встроенный Unity Transport 6.6.0. Реализован первый игровой срез: два сетевых игрока, изометрическая камера, коробки и совместный диван, сдача, квота, таймер, эвакуация и перезапуск. Это greybox-прототип, без финального арта и Steamworks. Результаты и границы проверки — в отчёте QA.

## Синхронизация

Основная ветка — `main`, удалённый репозиторий — `origin`.

Получить изменения: `git pull --ff-only`.

Отправить выбранные изменения: `git add <files>`, `git commit -m "Описание изменений"`, `git push`.

GitHub Desktop должен открывать корень рабочего клона. Изменения файлов этого клона видны в Changes после обновления приложения; коммит для этого не нужен. После коммита они переходят в History. Передача на GitHub требует Push, получение чужих изменений — Fetch/Pull. Фоновая автоматическая отправка не настроена.

В Git сохраняются Unity `Assets` вместе с `.meta`, `Packages` и `ProjectSettings`. Кэш `Library`, временные файлы и локальные настройки исключены. В текущем проекте уже включены Visible Meta Files и текстовая сериализация.
