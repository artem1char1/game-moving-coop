# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- Клавиши движения меняются при каждой новой попытке. Текущая раскладка показана в виджете «Управление».
- Для прыжка выполните жест из виджета внутри окна Game без нажатия кнопок мыши: круг, движение влево и обратно или движение вверх и обратно.

Пересечение синей линии запускает гонку с тремя ботами и отсчёт 30 секунд. Побеждает первый на финише. Табло справа показывает места, время и отметки о тех, кто не финишировал. Перепрыгните оранжевые барьеры, обойдите фиолетовые стены и пересеките зелёный финиш. Бирюзовые столбы в проходах можно обойти сбоку или пересечь, пока они опущены. Нажмите R, чтобы вернуться на старт, сбросить таймер и получить новую расстановку препятствий. Для будущей 3D-модели замените визуальные объекты внутри `ModelRoot`. Предыдущая концепция переезда сохранена в истории Git на коммите `5ec13b5`.
