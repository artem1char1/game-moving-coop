# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- `I` — вперёд, `J` — влево, `K` — назад, `L` — вправо.
- Для прыжка быстро нарисуйте мышью круг по или против часовой стрелки без нажатия кнопок.

В сцене плоская арена, временный персонаж и фиксированная перспективная камера. Для будущей 3D-модели замените визуальные объекты внутри `ModelRoot`. Предыдущая концепция переезда сохранена в истории Git на коммите `5ec13b5`.
