# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- Клавиши движения меняются при каждой новой попытке. Текущая раскладка показана в виджете «Управление». Удерживайте нужную клавишу и продолжайте крутить колесо вверх для движения вперёд или назад, вниз для движения влево или вправо.
- Для прыжка выполните жест из виджета внутри окна Game без нажатия кнопок мыши: круг, движение влево и обратно или движение вверх и обратно.
- Зажмите правую кнопку мыши и двигайте мышь, чтобы вращать камеру вокруг персонажа.

Пересечение синей линии запускает гонку с тремя ботами и счётчик прошедшего времени. Лимита времени нет. Побеждает первый на финише, а табло справа показывает места и время финиша. Генератор перемешивает 11 секций при каждой попытке. На четырёх развилках полосы также меняются местами. Можно обойти фиолетовую стену через свободный проход, перепрыгнуть оранжевый барьер или дождаться бирюзового блока. Маршрут можно менять между развилками. Два отдельных бирюзовых блока перекрывают трассу по всей ширине. Дождитесь, пока блок уйдёт в пол, и проходите. У каждого блока свой ритм. Нажмите R, чтобы вернуться на старт, сбросить таймер и получить новую расстановку препятствий. Для будущей 3D-модели замените визуальные объекты внутри `ModelRoot`.
