# Game Moving Coop

Текущий Unity-проект содержит локальное передвижение персонажа. Предыдущая концепция переезда сохранена в истории Git на коммите `5ec13b5`. Документы первой итерации относятся к прежней версии.

## Проверка в Unity

1. Откройте папку `game-moving-coop/` в Unity 6000.6.7f1.
2. Создайте временную пустую сцену. Если в ней уже есть камера, удалите её.
3. Перетащите `Assets/Game/MovementPlayer.prefab` в сцену и добавьте Plane для ориентира.
4. Нажмите Play, щёлкните в окне Game и используйте WASD.

Камера следует за персонажем. Движение ориентировано по экрану, диагональ сохраняет ту же скорость, а персонаж плавно поворачивается по ходу движения. Для новой 3D-модели замените визуальные объекты внутри `ModelRoot`.
