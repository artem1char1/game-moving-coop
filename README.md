# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- Клавиши движения и жест прыжка меняются при каждой попытке. Подсказка находится в виджете «Управление».
- Удерживайте клавишу и крутите колесо вверх для движения вперёд или назад, вниз для движения влево или вправо.
- Зажмите ПКМ и двигайте мышь, чтобы вращать камеру. Направления движения закреплены за осями карты.
- R запускает новую попытку с другой картой.

Синяя линия запускает гонку с тремя ботами. Лимита времени нет. Побеждает первый на зелёном финише, табло справа показывает места и время.

Генератор строит связный лабиринт из 80 участков. Непрерывные продольные стены соединяют границы соседних участков. В карте есть развилки, как минимум три пути к выходу и защищённый от удаления тупик. Между четырьмя частями карты переходы находятся с чередующихся сторон, что вынуждает менять направление. Высокие стены ограничивают переходы между коридорами. В открытых проходах размещаются 18 низких барьеров и три движущихся блока. Боты ищут путь по той же карте, по которой движется игрок.
