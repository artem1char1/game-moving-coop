# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- `I` — вперёд, `J` — влево, `K` — назад, `L` — вправо.
- Для прыжка нарисуйте курсором круг внутри окна Game за пару секунд. Подходит любое направление, кнопки мыши нажимать не нужно.

Синяя линия запускает отсчёт 30 секунд. Перепрыгните оранжевые барьеры, обойдите фиолетовые стены и пересеките зелёный финиш. Нажмите R, чтобы вернуться на старт и сбросить таймер. Для будущей 3D-модели замените визуальные объекты внутри `ModelRoot`. Предыдущая концепция переезда сохранена в истории Git на коммите `5ec13b5`.
