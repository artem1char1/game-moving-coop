# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- Клавиши движения меняются при каждой новой попытке. Текущая раскладка показана в виджете «Управление».
- Для прыжка выполните жест из виджета внутри окна Game без нажатия кнопок мыши: круг, движение влево и обратно или движение вверх и обратно.

Синяя линия запускает отсчёт 30 секунд. Перепрыгните оранжевые барьеры, обойдите фиолетовые стены и пересеките зелёный финиш. Нажмите R, чтобы вернуться на старт, сбросить таймер и получить новую расстановку препятствий. Для будущей 3D-модели замените визуальные объекты внутри `ModelRoot`. Предыдущая концепция переезда сохранена в истории Git на коммите `5ec13b5`.
