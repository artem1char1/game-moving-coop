# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play и щёлкните в окне Game.

- Клавиши движения меняются при каждой новой попытке. Текущая раскладка показана в виджете «Управление». Удерживайте нужную клавишу и продолжайте крутить колесо вверх для движения вперёд или назад, вниз для движения влево или вправо.
- Для прыжка выполните жест из виджета внутри окна Game без нажатия кнопок мыши: круг, движение влево и обратно или движение вверх и обратно.
- Зажмите правую кнопку мыши и двигайте мышь, чтобы вращать камеру вокруг персонажа.

Пересечение синей линии запускает гонку с тремя ботами и счётчик прошедшего времени. Лимита времени нет. Побеждает первый на финише, а табло справа показывает места и время финиша. Порядок препятствий меняется: на каждой трассе есть два обязательных прыжка и центральный блок с проходами по обе стороны. Перепрыгните оранжевые барьеры, обойдите фиолетовые стены и пересеките зелёный финиш. При каждой попытке бирюзовые столбы получают случайную ширину и свой ритм движения. Их можно обойти сбоку или пересечь, пока они опущены. Нажмите R, чтобы вернуться на старт, сбросить таймер и получить новую расстановку препятствий. Для будущей 3D-модели замените визуальные объекты внутри `ModelRoot`. Предыдущая концепция переезда сохранена в истории Git на коммите `5ec13b5`.
