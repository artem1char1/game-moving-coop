# game-moving-coop

Проект кооперативной игры для Steam: изометрия, простая мультяшная графика, переноска мебели и денежная квота.

Сейчас сохранены визуальные концепты, роли субагентов и предварительный план. Разработка игрового кода не начата, движок не выбран.

## Материалы

- `outputs/` — концепты и памятка команды.
- `AGENTS.md` — порядок работы и передачи задач.
- `.codex/agents/` — роли PM, gamedev-разработчика и QA.
- `work/production/` — план и отчёты проверок.

## Синхронизация

Основная ветка — `main`, удалённый репозиторий — `origin`.

Получить изменения: `git pull --ff-only`.

Отправить выбранные изменения: `git add <files>`, `git commit -m "Описание изменений"`, `git push`.

Синхронизация выполняется командами Git; фоновая автоматическая отправка не настроена.
