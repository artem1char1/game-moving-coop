# Game Moving Coop

В Unity 6000.6.7f1 откройте `Assets/Game/MovementArena.unity`, нажмите Play. В меню выберите «Лабиринт», «Полоса препятствий» или «Случайно», затем нажмите «Начать».

- Клавиши движения и жест прыжка меняются при каждой попытке. Подсказка находится в виджете «Управление».
- Удерживайте клавишу и крутите колесо вверх для движения вперёд или назад, вниз для движения влево или вправо.
- Зажмите ПКМ и двигайте мышь, чтобы вращать камеру. Направления движения закреплены за осями карты.
- R возвращает в меню выбора карты. «Случайно» выбирает один из двух генераторов при нажатии «Начать».

Синяя линия запускает гонку с тремя ботами. Лимита времени нет. Побеждает первый на зелёном финише, табло справа показывает места и время.

Режим «Лабиринт» строит связную карту из 80 участков. Непрерывные продольные стены соединяют границы соседних участков. В карте есть развилки, как минимум три пути к выходу и защищённый от удаления тупик. Между четырьмя частями карты переходы находятся с чередующихся сторон, что вынуждает менять направление. Высокие стены ограничивают переходы между коридорами. В открытых проходах размещаются 18 низких барьеров и три движущихся блока. Боты ищут путь по той же карте, по которой движется игрок.

Режим «Полоса препятствий» перемешивает 18 секций: четыре развилки с обходом, прыжком и ожиданием, четыре продольные стены, непрерывно доходящие до следующего препятствия, барьеры и движущиеся блоки. Три высокие стены с чередующимися сторонами прохода заставляют обходить препятствия. Боты используют маршрут выбранного генератора.
